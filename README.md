# BUET-EEE-416-Storm-Drain-Network-Firmware-January-2026-A1-G03-
ESP32 and LoRa network that tells a blocked storm drain apart from one filled by heavy rain. Three nodes measure water depth and rainfall, and a gateway combines their readings with a forecast to give each drain a verdict. Built for EEE 416 at BUET, January 2026, Section A1, Group 03.
